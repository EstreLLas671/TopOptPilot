# TopOptPilot 2.1.3 使用说明

> 面向 Windows 的二维/三维结构拓扑优化、工程开发与可审计 AI 科研工作台<br>
> 文档版本：2.1.3<br>
> 更新日期：2026-09-05<br>
> 项目主页：https://github.com/EstreLLas671/TopOptPilot

## 1. TopOptPilot 是什么

TopOptPilot 将真实有限元拓扑优化、工程文件开发、AI 对话和受控科研实验放在同一个桌面客户端中。它不是仅展示示例数据的可视化程序：正式工程运行使用 MATLAB 或 Python FEM 求解器，迭代图、密度、应力、指标、报告和科研结论都必须来自实际运行制品。

客户端包含两个长期保活、彼此隔离的工作区：

- **工程开发**：打开项目、编辑源码、配置拓扑优化参数、启动或停止求解、查看 MATLAB 逐轮大图、分析最终 2D/3D 密度和应力、保存与比较方案、生成工程报告。
- **AI 科研**：创建 Research、维护研究目标和假设、导入工程基线、与默认模型沟通、审批参数建议、运行“三方案比较—优选—诊断—再优化”流程、查看证据与最终方案、导出专业科研报告和复现包。

工程运行不会自动成为科研实验。只有用户明确保存工程方案并导入 Research，或显式创建科研基线，工程证据才会进入科研状态。

## 2. 核心能力一览

### 2.1 工程求解与结果

- 支持 2D 和 3D 拓扑优化。
- 支持悬臂梁、MBB 梁、简支梁和 L 型支架等工况。
- MATLAB 是默认正式后端；Python FEM 为可选后端。
- 支持网格、体积分数、惩罚因子、滤波半径、迭代范围、滤波策略和材料参数。
- MATLAB 每轮可发布真实 PNG、密度、可用时的应力、指标和 SHA-256。
- 迭代可视化以 MATLAB 原图为主，大图下方保留真实进度条和迭代滑块。
- 3D 密度/应力支持连续等值曲面、单元网格、旋转、平移、缩放、重置和全屏。
- 结果读取采用 manifest 与 Float32 制品，支持 MATLAB F-order。
- 真实指标包括柔度、体积分数、灰度率、连通分量和最大 Von Mises 应力。
- 可保存方案、重命名方案、打开详情及进行双方案比较。

### 2.2 AI 对话与附件

- 文本、图片和文档统一使用设置中的默认模型。
- 支持 PNG、JPEG、WebP、SVG、PDF、DOCX、XLSX、TXT、Markdown 和 CSV。
- 可点击附件按钮，也可将文件直接拖入工程或科研聊天中栏。
- 每条消息最多 4 个附件；单个附件默认不超过 10 MB。
- 使用文件头、扩展名和 SHA-256 做格式校验与去重。
- 默认模型不支持某类输入时返回明确错误，不静默更换模型，不生成虚假回复。
- 工程聊天草稿按项目与会话隔离；页面切换后保留文字、附件和源代码发送许可。
- 消息、长路径、哈希和代码都限制在聊天区域内，不会撑破界面。

### 2.3 AI 科研与审计

- Research State 是科研流程的唯一权威状态。
- 研究目标、研究假设、参数、实验、失败原因、审批、反思摘要和制品均可追溯。
- 支持 Policy、Safety、Budget 与 F0–F3 审批链。
- 保真度映射固定为：`F0/F1=Python 2D`、`F2=Python 3D`、`F3=MATLAB MCP`；F3 需要人工审批。
- 失败实验作为有效证据保留，不能被替换成模拟成功结果。
- 自主研究每轮生成 3 套不同角度的候选方案，运行真实实验后比较、优选、诊断并形成下一轮建议。
- 目标、假设和参数建议必须经弹窗确认后才能填入，不会自动启动实验。
- 最终方案不会在切换 Research 时自动弹出；只有点击“查看最终方案”才会显示。

### 2.4 专业报告

- AI 科研报告默认同时生成 Markdown、PDF 和图像资源目录。
- 报告采用专业中文字段，不暴露 `volfrac`、`gray_ratio` 等代码变量名。
- 报告严格使用真实 Research State、求解结果和证据；缺失信息显示“未提供”或“未计算”。
- 三维结果图由真实三维密度生成，不以二维投影冒充三维结构。
- 报告图表采用黑、白、灰配色，包含真实三维拓扑、应力分布和收敛曲线。
- 同名文件必须显式确认覆盖；生成完成后返回路径、大小和 SHA-256。

## 3. 安装与系统要求

### 3.1 推荐环境

- Windows 10 或 Windows 11，64 位。
- 最低窗口尺寸 920×640，推荐 1280×800 以上。
- 建议至少预留 2 GB 安装空间；大网格实验还需要额外运行空间。
- 正式 MATLAB 求解需要本机安装完整 MATLAB。推荐 R2024b，其他版本以客户端真实探测结果为准。
- 在线 AI 对话需要可访问的 DashScope/Qwen 兼容服务、API Key 和默认模型。

### 3.2 下载安装包

从 [GitHub Releases](https://github.com/EstreLLas671/TopOptPilot/releases) 下载：

```text
TopOptPilot_2.1.3_x64-setup.exe
```

发布页同时提供安装包大小、SHA-256、签名状态和版本说明。当前安装包未进行商业代码签名时，Windows SmartScreen 可能显示“未知发布者”；请先核对 SHA-256，再决定是否运行。

### 3.3 安装包包含与不包含的内容

标准安装包包含：

- Tauri + React 桌面客户端；
- TopOptPilot Python sidecar；
- Agent 运行组件；
- Node.js 与 Pi 运行资源；
- MCP 适配器和 MATLAB MCP 组件；
- MATLAB 2D/3D 工程求解脚本；
- 参数预览案例资源。

标准安装包不包含：

- MATLAB 本体或 MATLAB Runtime；
- API Key、授权头或模型权重；
- 用户聊天、Research、审批记录、运行日志或本机数据库；
- `matlab/dist`；
- 开发缓存、测试数据、`.debug-data`、`.worktrees`、`node_modules` 源目录和 Rust `target` 源目录。

### 3.4 首次启动

1. 启动 TopOptPilot。
2. 客户端启动本地 sidecar 与受控服务。
3. 读取环境缓存并检查 MATLAB 路径。
4. 缓存无效时执行 MATLAB 自动发现和真实握手。
5. 恢复上次选择的工作区、项目、参数、会话和最近运行。
6. 默认进入“工程开发 → 聊天”。

切换“工程开发”和“AI 科研”只切换界面，不会取消正在运行的 MATLAB 任务，也不会重复探测环境。

### 3.5 无界面 / Agent 使用（无需打开桌面客户端）

仓库同时提供受 Policy 约束的 `topoptctl`。Codex、Pi、CI 或其他能够执行本地命令的 Agent 可以通过它完成 MATLAB 设置、Qwen 连接、工程基线的计划/真实运行/取消/导出，以及受控的 Research 流程；不需要启动 Tauri 或 Streamlit 窗口。

首次从源码仓库使用时，在仓库根目录执行下面的引导器：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\bootstrap_headless.ps1
```

它只会在仓库内创建或复用 `.venv`、安装 Python 依赖，并在 Pi 运行时缺失时以 `npm ci --ignore-scripts` 安装锁定依赖。它**不会**保存或读取 API Key、启动 Sidecar、启动 MATLAB、运行工程任务或提交 Research。已有 `node_modules` 不会被默认覆盖；若人工检查后确实需要重装，才显式加入 `-ReinstallPiRuntime`。

然后为当前无界面会话选择独立状态目录，并启动受认证、仅监听 `127.0.0.1` 的 Sidecar：

```powershell
$state = Join-Path $env:LOCALAPPDATA "TopOptPilot\headless"
.\topoptctl.cmd --data-dir $state daemon start
.\topoptctl.cmd --data-dir $state doctor
```

Agent 必须先执行 `engineering plan`，只有用户明确授权真实计算时才可附加 `--confirm` 执行 `engineering run start`；不能把自然语言“开始”或任务 JSON 当作确认。外部 Agent 也不得绕过 `topoptctl` 调用任意 MATLAB、Shell、数据库或未白名单的 Policy 工具。

完整命令、严格 JSON 任务格式、Qwen 凭据的安全输入方式、真实 2D 闭环、取消、哈希导出以及 Agent 调用规则见 [无界面命令手册](docs/topoptctl.md)；架构决策和已完成的实机验证分别见 [ADR-0004](docs/decisions/ADR-0004-headless-topoptctl.md) 与 [验证记录](docs/validation/2026-08-30-topoptctl-headless-e2e.md)。

## 4. 设置中心

点击窗口右上角“设置”进入设置中心。

### 4.1 通用与主题

可配置默认语言、界面密度、启动行为和主题。控件修改先进入草稿，只有点击本板块的“应用”才会保存并改变界面；关闭设置页会放弃未应用的通用设置。

主题支持浅色、暗色、跟随系统和自定义语义色板。自定义项包括页面、面板、浮层、文字、次文字、边框、强调、成功、警告、错误、图表与 3D 背景，并支持界面对比度调节。Monaco 编辑器、图表和三维画布会随主题同步。

### 4.2 Agent 与模型

1. 填写兼容服务地址。
2. 设置默认模型，例如 `qwen3.7-plus`。
3. 输入 API Key。
4. 点击“安全保存密钥”。
5. 点击“测试连接”。
6. 测试结果只显示在“Agent 与模型”板块。
7. 如会话状态异常，可点击“重启所有 Pi 会话”。

文本、图片和其他附件均使用这里的默认模型。应用不会为图片偷偷切换到另一个视觉模型。

API Key 通过受限凭据接口保存，不进入普通设置、日志、报告、错误响应或 Git 仓库。环境变量 `DASHSCOPE_API_KEY` 可用于开发或无头环境。

## 5. 工程开发界面

### 5.1 左栏：工程工作区与历史对话

“工作区”用于打开项目、搜索文件、刷新项目、新建文件和选择文件。“历史对话”显示当前工程范围内的会话，可新建、切换、重命名和删除。

打开工程：

1. 点击“打开项目文件夹”。
2. 选择包含 MATLAB、Python、配置或说明文件的工程目录。
3. 在文件树中选择文件。
4. 切换到“代码”标签查看或编辑。
5. 修改后点击“保存”；聊天和 AI 建议不会自动写盘。

历史会话使用最新请求优先机制。快速连续切换时，较旧响应不能覆盖最后一次选择；删除当前会话后会选择下一条会话。聊天草稿不会串到其他项目或会话。

### 5.2 中栏标签

- **聊天**：工程问答、附件、参数建议。
- **代码**：Monaco 编辑器、受控 PatchProposal。
- **结果**：最终指标、2D/3D 密度与应力、收敛曲线和制品。
- **迭代可视化**：MATLAB 每轮原图、密度、应力、滑块和进度。
- **参数调整与对比**：当前方案、已保存方案、详情和双方案比较。

### 5.3 右栏：环境与参数

MATLAB 模式显示本机 MATLAB 的路径、版本、探测状态和诊断。自动检测失败时可手动选择 MATLAB 安装根目录或 `bin` 目录。Python 模式只显示 Python 相关配置，不显示“本机 MATLAB”和“MATLAB Runtime”。

点击“打开详细参数”进入参数配置窗口。参数只在点击“应用配置”后生效。

## 6. 工程完整实验步骤

以下流程适用于一次从配置到报告的完整 2D/3D 工程实验。

### 步骤 1：确认问题与项目

1. 打开工程目录。
2. 确认当前代码、输入数据和输出目录。
3. 如需 AI 阅读源码，必须在该次消息中明确勾选源代码发送许可。
4. 如只进行标准拓扑优化，可直接进入参数配置。

### 步骤 2：选择求解后端

- 选择 **MATLAB**：用于正式 MATLAB 工程求解与逐轮 PNG。
- 选择 **Python**：用于内置 FEM 验证或科研低/中保真流程。

MATLAB 不可用时：

1. 点击重新检测。
2. 检查 MATLAB 许可证。
3. 手动选择 MATLAB 路径。
4. 必要时在系统命令行验证 `matlab -batch "disp(version)"`。

### 步骤 3：设置维度、工况和网格

1. 选择 2D 或 3D。
2. 选择悬臂梁、MBB 梁、简支梁或 L 型支架。
3. 设置 X/Y/Z 方向单元数。2D 的 Z 向单元数为 1。
4. 参数预览只显示真实 MATLAB 案例密度/曲面；资源缺失时显示“案例预览不可用”，不会生成替代图。

网格越细，计算量和内存占用越高。首次验证建议使用小网格，确认全链路后再提高分辨率。

### 步骤 4：设置优化参数

- **体积分数**：允许保留的材料比例，范围为 `(0, 1]`。
- **惩罚因子**：SIMP 惩罚参数，通常不小于 1。
- **滤波半径**：抑制棋盘格和网格依赖，必须大于 0。
- **最小/最大迭代次数**：最小迭代不得大于最大迭代。
- **滤波策略**：固定半径或自适应策略。

灰度率定义为密度严格位于 `(0.1, 0.9)` 的单元比例。该指标用于描述中间密度单元比例，不等同于图像颜色灰度。

### 步骤 5：设置材料与单位

可选择内置参考材料、结构钢、6061-T6 铝合金、Ti-6Al-4V 或自定义材料。自定义材料至少核对：

- 杨氏模量；
- 泊松比；
- 密度；
- 屈服/许用应力（如需强度判定）；
- 几何、载荷和材料的单位链。

只有几何、载荷、材料和求解器单位链完整可信时，最大 Von Mises 应力才以 MPa 呈现并与许用应力比较。单位链不完整时只显示“归一化最大应力”，不得宣称满足强度要求。

### 步骤 6：应用配置并开始优化

1. 点击“应用配置”。
2. 点击“开始优化”。
3. 按钮在 queued/running 状态变为“停止优化”。
4. 新运行自动切换到“迭代可视化 → MATLAB 原图”。
5. 下栏自动打开并显示真实运行输出。

点击“停止优化”会调用取消接口并保留已产生的 PNG、密度、应力、日志和 manifest。

### 步骤 7：查看逐轮 MATLAB 大图

每个有效 MATLAB 迭代帧包含运行 ID、迭代号、PNG 路径、密度、可选应力、真实指标和 SHA-256。

界面布局为：

1. 上方显示当前迭代 MATLAB PNG 大图。
2. 大图下方显示真实进度条。
3. 显示当前轮次与最大轮次。
4. 滑块可选择历史迭代。

运行时默认跟随最新帧。用户手动拖动滑块后暂停自动跟随；新图加载期间保留上一帧。相同快照按 `runId + snapshotPath` 缓存，相邻帧会预取。

没有真实 PNG 时不会生成模拟图。首帧到达前只显示真实阶段、最近 MATLAB 输出和进度。

### 步骤 8：查看最终结果

运行完成后进入“结果”：

- 核对柔度、体积分数、灰度率和连通性。
- 核对最大 Von Mises 应力、单位和单位可信度。
- 查看 2D 场图或 3D 连续等值曲面。
- 切换密度/应力时保持旋转、缩放和平移状态。
- 查看带坐标轴的柔度收敛曲线。
- 检查 manifest、制品路径、SHA-256 和求解后端。

如果最终 manifest 尚未落盘，客户端会执行有限次数的制品对账；超过上限后显示明确错误和重试入口，不会无限停留在“加载中”。

### 步骤 9：保存和比较方案

1. 打开“参数调整与对比”。
2. 点击“保存当前运行”。
3. 在浮窗中输入必填方案名称。
4. 保存后选择方案查看人类可读配置和真实结果。
5. 可选择第二个方案进行并排比较。

方案详情显示维度、工况、网格、材料、体积分数、惩罚因子、滤波半径、迭代范围、求解链路和真实指标，不以整段 JSON 代替说明。

### 步骤 10：导出工程报告或进入科研

工程报告：

1. 点击“生成运行报告”。
2. 输入报告名称。
3. 选择文件夹或手动输入目录。
4. 核对最终路径与 SHA-256。

进入 AI 科研有两种方式：

- 创建科研基线；
- 先保存工程方案，再在科研 Composer 的“+”中导入。

导入只填入 Research 参数和真实基线，不会自动运行实验。

## 7. 工程 Agent 与受控补丁

### 7.1 工程聊天

可询问代码、参数、MATLAB 输出、结果或错误。打开会话时默认定位到最后一条消息；用户向上阅读时不会被新消息强制拉回底部。

当模型返回合法完整参数建议时，界面展示当前值与建议值的差异。点击“填入参数”只更新配置草稿，不自动开始优化。

### 7.2 PatchProposal

AI 不能直接修改工程文件。标准流程：

1. 保存当前文件并描述修改目标。
2. 明确允许本次发送源码。
3. Agent 生成候选 unified diff。
4. 点击“校验差异”。
5. 查看预览与一次性审批凭证。
6. 点击“确认应用”。
7. 最后由用户保存文件。

项目、文件摘要或差异在审批过程中变化时，旧凭证立即失效。

## 8. AI 科研完整实验步骤

### 步骤 1：创建 Research

1. 切换顶部“AI 科研”。
2. 点击“新建研究”。
3. 在浮窗中填写 1–120 字的名称。
4. 创建后自动选择该 Research。

Research 的目标和假设允许暂时为空，但空目标时不能启动自主研究。

### 步骤 2：填写研究目标与假设

右栏依次为：

1. 研究目标；
2. 研究假设；
3. 参数配置；
4. 结果呈现。

目标应描述要优化的结构、约束和评价方向；假设应是可以通过实验比较验证或否定的陈述。保存后会写入 Research State、版本历史和审计事件。

如果目标或假设为空，也可以在科研对话中描述需求。默认模型可以给出目标、假设和完整参数建议；合法建议会弹出差异确认窗。只有点击“批准并填入”才会写入，不会自动运行。

### 步骤 3：配置科研参数或导入工程方案

可以手动打开科研详细参数，也可以点击科研 Composer 左侧“+”导入工程方案。

只有满足以下条件的工程方案可导入：

- 工程运行已经 completed；
- 方案完整性为 verified；
- 配置、指标和来源证据可读取。

导入后记录方案名称、Run ID、配置摘要、哈希和真实指标，并写入本地系统消息及审计事件。

### 步骤 4：启动自主研究

点击“运行自主研究”。如果目标为空，流程会停止并提示先填写目标。

每一轮使用 8 个真实阶段：

1. **上下文与基线**：读取目标、假设、预算、工程基线和历史真实结果。
2. **三方案规划**：从不同角度形成 3 套完整候选方案。
3. **Policy 与审批**：校验安全、预算、参数范围和保真度权限。
4. **真实实验执行**：分别执行被批准的候选方案。
5. **结果比较**：比较柔度、体积分数、灰度率、连通性、最大应力和运行状态。
6. **优选路线**：只依据真实结果选择当前最佳方案。
7. **问题诊断与反思**：记录观察、证据、判断理由摘要和限制，不保存隐藏思维链。
8. **下一轮建议或终止**：形成下一轮参数建议，继续执行仍需审批。

三套方案通常从不同角度改进，例如：

- 惩罚因子和滤波策略；
- 网格、体积分数或迭代预算；
- 载荷、材料、结构连通性或应力约束。

某一方案失败时，失败原因作为完成项进入比较，其他方案仍可继续。系统不会为失败方案补造指标。

### 步骤 5：处理审批

在“过程 / 审计”标签查看待审批项：

1. 核对候选方案、Fidelity、风险、预算和理由。
2. 点击“批准并提交”或“拒绝”。
3. MATLAB/F3 必须显式人工批准。
4. 拒绝不会修改研究目标或静默放宽约束。

### 步骤 6：观察科研进度

中栏上方显示当前轮阶段进度条，百分比只由真实阶段完成事件计算，不按时间估算。

下栏“科研执行进度”按步骤展示：

- 当前工作内容；
- 等待、进行中、完成或失败状态；
- 真实结果或失败原因；
- 当前方案反思摘要；
- 实验、工程基线和证据 ID；
- 下一步动作或审批要求。

切换到工程开发不会中断科研或工程后台运行；切回后会恢复当前状态。

### 步骤 7：查看真实结果与最终方案

右栏“结果呈现”显示实验状态、柔度、灰度率、最大应力、实验列表、制品和三方案流程。

切换 Research 或实验时会立即更新选中 ID，并取消旧详情请求；旧响应不能覆盖新选择。

最终方案只通过左侧“查看最终方案”打开。没有真实最佳实验时按钮禁用。详情包括：

- 人类可读参数；
- 柔度、体积分数、灰度率、连通性；
- 最大 Von Mises 应力、单位和证据；
- 2D 密度场或真实 3D 密度曲面；
- 真实应力存在时的应力视图；
- 柔度收敛曲线；
- 求解器、Fidelity、实验状态和证据摘要。

### 步骤 8：导出科研报告

1. 在“结果呈现”点击“生成报告”。
2. 输入必填报告名称。
3. 点击文件夹按钮选择目录，或手动输入完整路径。
4. 默认同时生成 Markdown 和 PDF。
5. 同名文件存在时勾选覆盖确认。
6. 点击“生成报告”。
7. 完成后核对 Markdown、PDF、资源目录、文件大小和 SHA-256。

输出结构：

```text
<报告名>.md
<报告名>.pdf
<报告名>_assets/
```

Markdown 使用相对图像路径；PDF 内嵌同一批图像。报告先写入临时目录，全部成功后再原子移动到目标目录。

报告章节依次覆盖任务摘要、关键参数与工程约束、算法与融合策略、核心结果对比、可交付文件、结论与审查意见，并按数据可用性补充摘要和知识来源。

### 步骤 9：生成复现包

复现包是独立功能，不与报告混合。它用于保存配置、实验引用、证据摘要和复现入口；API Key、授权头、原始附件路径和用户隐私数据不会进入复现包。

## 9. 指标解释

| 指标 | 含义 | 使用注意 |
|---|---|---|
| 柔度 | 结构在当前边界和载荷下的柔顺程度 | 同一工况、材料、网格和约束下通常越低越好 |
| 体积分数 | 最终材料体积占设计域比例 | 应与配置约束共同核对 |
| 灰度率 | 密度位于 `(0.1, 0.9)` 的单元比例 | 越低通常表示中间密度更少 |
| 连通分量 | 阈值化结构的连通区域数量 | 需要结合工况和制造要求解释 |
| 最大 Von Mises 应力 | 单元应力后处理的最大值 | 只有单位链可信时才能标为 MPa |
| 柔度收敛 | 各迭代柔度历史 | 用于判断收敛趋势，不替代网格无关性检查 |

TopOptPilot 当前不会自动完成屈曲、疲劳、连接节点、完整制造约束和网格无关性论证。未计算项必须明确标记，不能视为已满足。

## 10. 会话、附件与数据保存

- 工程和科研首次进入时不会自动创建空白测试会话。
- 首次发送、上传附件或显式新建时才创建会话。
- 会话消息与附件保存在本机用户数据目录，不进入安装包或 Git 仓库。
- 打开对话默认滚动到最新消息。
- 删除会话只影响对应会话，不删除工程运行制品。
- Research 移入回收站不会立即删除实验、报告和证据。

典型本机数据包括环境缓存、会话索引、消息 JSONL、内容寻址附件、Research 数据库、工程运行和制品。升级前如需迁移，请先完整备份用户数据目录。

## 11. 安全与真实性边界

- 不生成虚假 FEM 指标、求解状态或实验历史。
- 确定性评估器未判定可行时，不宣称实验成功。
- 低保真结果不能冒充 F3/MATLAB 证据。
- MATLAB MCP 失败不能回退为 Python 并宣称 F3 成功。
- AI 科研不能绕过 Policy、预算和 F0–F3 审批。
- Agent 不能静默修改研究目标或放宽约束。
- 工程 Agent 只能生成候选 PatchProposal，应用前必须预览并确认。
- 没有真实快照、密度或应力时，不生成替代图和模拟数值。
- API Key、授权头和原始本地路径不得进入日志、报告、错误响应或普通设置。
- 报告中的结论必须能够回溯到 Research State、求解器结果或证据 ID。

## 12. 常见问题

### 12.1 MATLAB 检测不到

确认安装的是完整 MATLAB；点击重新检测，或手动选择安装根目录/`bin` 目录。检查许可证以及 `matlab -batch` 是否能正常启动。

### 12.2 只有进度条，没有 MATLAB 图

首帧前只显示阶段和进度是正常的。若运行结束仍无图，检查求解器是否开启逐轮渲染、manifest 是否包含 `render_file`、PNG 是否存在以及 SHA-256 是否通过。界面不会生成模拟图。

### 12.3 结果一直加载

2.0.3 会并行读取 manifest、density、stress 和 history，并对完成运行进行有限次数索引对账。若仍失败，使用结果区域的明确错误/重试信息检查制品是否完整。

### 12.4 应力为什么不是 MPa

只有 N/mm/MPa 等单位链完整、材料与几何尺度可信时才显示 MPa。否则显示归一化应力，避免错误强度结论。

### 12.5 Agent 显示 Safe Mode 或 not configured

在“Agent 与模型”中保存 API Key、默认模型和服务地址，再执行测试连接。必要时重启 Pi 会话。离线时工程求解与结果查看仍可使用。

### 12.6 文件拖入失败

检查格式、单文件大小和单条消息数量。某些聊天软件提供的是不可读临时对象，需先另存为本地文件再上传。

### 12.7 切换 Research 或历史对话卡顿

2.0.3 已加入请求序号、旧请求取消、局部列表更新和单飞对账。如果仍出现问题，请记录最后点击的 Research/会话、时间和错误提示，不要上传包含 API Key 的日志。

### 12.8 最终方案为什么不自动弹出

这是预期设计。为了避免切换 Research 时打断操作，最终方案只能由“查看最终方案”按钮显式打开。

### 12.9 报告未生成

确认报告名有效、目标目录可写、同名文件是否需要覆盖，并检查 Research 是否至少包含可用的真实实验。缺失三维或应力证据不会伪造图像，报告会写明未产生相应结果。
