# TopOptPilot 2.0.2 本地构建说明

TopOptPilot 2.0.2 集中修缮设置应用边界、工程与科研聊天交互，以及可恢复的自主科研流程。本版本仅生成本地安装包，不对应自动创建的 GitHub Release。

## 设置与聊天

- 通用设置改为草稿模式，只有点击“应用”才保存并立即改变语言、密度、主题与启动行为。
- Agent 连接测试结果只显示在“Agent 与模型”板块。
- 工程和科研不再因页面挂载创建空会话；首次发送、上传、显式新建或导入方案时才创建。
- 一次性清理仅覆盖标题明确为测试、演示、样例、test 或 demo 且消息数为零的旧会话。
- 两套 Composer 支持中栏整体拖放，上传、发送和加载图标统一居中；打开会话默认定位到最新消息。

## 工程与科研协作

- 工程迭代进度元信息仅保留当前轮数。
- 已完成且完整性验证通过的工程方案可导入当前 Research，作为真实基线并填入参数草稿，但不会自动运行。
- 目标或假设缺失时，默认模型可返回完整受限建议；若首次回复缺少结构化动作，会由同一默认模型执行一次只读提取重试。
- 建议必须经过确认弹窗，批准后才写入目标、假设与完整参数配置，并留下审计事件。

## 自主科研与真实结果

- 当前轮工作流分为上下文、三方案规划、审批、真实实验、比较、优选、诊断与下一轮建议八个阶段。
- 中栏显示真实阶段进度，下栏步骤卡记录工作内容、真实结果或失败原因、反思摘要、证据 ID 与下一步。
- 工程基线、当前真实实验和历史最优结果按固定优先级用于评估；不使用演示指标代替实验结论。
- 新增真实科研密度/应力可视化接口，统一采用 little-endian Float32 与 MATLAB F-order。
- 最终方案支持 2D 密度场、3D 可交互密度曲面、真实应力、收敛曲线、参数和证据摘要，并可在结束后重复查看。
