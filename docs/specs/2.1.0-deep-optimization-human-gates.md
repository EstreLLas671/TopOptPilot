# TopOptPilot 2.1.0：深度优化人工逐步审批

- 两个工作区统一为“基础实现”和“深度优化”。
- Step1–Step4 依次对应 Python 2D 粗网络、Python 2D 自适应粗网络、Python 3D 粗网络、MATLAB 3D 真实网络；旧名称仅作兼容输入。
- 删除实验次数预算门禁；保留单次求解超时、停止、Policy 和参数安全校验。
- 每次人工决策只授权一轮；本轮结束立即暂停。数值未达标不阻止推进，只有无有效真实结果时禁止推进。
- 实验成败只反映求解有效性（真实收敛、指标完备）；契约阈值（灰度率、连通性、应力）是审查条件与优化方向，以"目标差距"呈现并驱动下一轮方向建议，不作为成败门禁。
- Step1–Step3 每轮授权生成三个不同方向的受控候选并全部真实求解；轮末由确定性评估器对比各候选的连通性、灰度率与柔度（连通优先、灰度次之、柔度收尾）选出本轮最优方案，阶段弹窗只呈现该最优方案。
- 用户选"否"则不以该方案为基线、重新生成三套对比方案；选"是"则以本轮最优方案为基线进入下一 Step，下一轮候选全部从该基线派生（单因子受控）。Step4 继承 Step3 最优方案的参数不变，用 MATLAB 高精度网格重新求解，求解期间逐轮回传实时优化快照至结果面板。
- 实验成败只反映求解有效性（真实收敛、指标完备）；契约阈值（灰度率、连通性、应力）是审查条件与优化方向，以"目标差距"呈现并驱动下一轮方向建议，不作为成败门禁。
- 推进门禁只要求本轮存在有效真实结果（含未达标的部分成功与失败筛选证据）；仅基础设施故障且无真实指标时只能重复本阶段。
- 阶段弹窗展示真实拓扑、柔度收敛及当前/目标指标；报告展示每个 Step 的最佳有效结果图。
- Agent 产生结构化待填字段时必须弹出可编辑建议窗口，普通说明不弹窗。
