# Causal Reasoning

Use a shared control and change one factor per experiment. Supported templates are:
`beta_vs_rmin`, `beta_vs_penal`, and `projection_vs_controller`. State what observation would favor
each explanation before compiling the intent. Do not generalize beyond the tested parameter range.
